# 无聊之作

three.js 三渲二微缩渔港游戏地图。当前版本包含 M1～M5，并依据 M3 审查意见修正布局与建模。岛台半径由 30 扩至 **38**，安全摆放半径为 **35**。船队为**四艘渔船、一艘小帆船和一艘小渡轮**；三艘渔船侧靠栈桥，另一艘在港池内。现在可操控人物沿村道走到渔村、石码头、三座木栈桥及鸟居。

## 运行

### 发给别人直接打开

打开 [离线版 HTML](dist/太阳雨渔港_离线版.html)，点击下载按钮保存文件，再用支持 WebGL 的浏览器双击打开。离线版已包含 Three.js 和游戏代码，可以单独分享，也能断网游玩。源码更新后，在项目目录运行 npm ci 和 npm run build:portable 即可重新生成。

### 源码预览

在本目录执行以下任一命令，然后访问 [http://127.0.0.1:8000/](http://127.0.0.1:8000/)：

```bash
python -m http.server 8000
```

或：

```bash
npx serve .
```

需联网加载固定版本 `three@0.160.0`。场景没有外部模型或贴图文件。启动后默认进入步行模式。

## 操作

- 步行模式：WASD 或方向键移动，Shift 快跑，空格跳跃；拖动旋转跟随镜头，滚轮缩放，双击复位镜头。人物会被房屋、树木、道具和水边阻挡。
- 触屏步行：左下角摇杆移动，右下角按钮跳跃，拖动画面旋转镜头。
- 点击右上角按钮或按 V，在步行模式和全岛观景模式之间切换。观景模式下拖动旋转、滚轮缩放、右键平移、双击复位；触屏双指缩放和平移。
- 点击“地图”或按 M，查看或收起显示玩家位置、朝向和地标的俯视小地图。

## 代码与参数

- `index.html`：入口、importmap 和文字提示。
- `main.js`：场景搭建与动画循环。`STATE` 集中保存后续天气系统共用参数。
- `game/player.js`：人物模型、键盘与触屏控制、跳跃、跟随镜头所需的移动、地形和障碍物判定。
- `game/minimap.js`：俯视地图、玩家位置和朝向。
- `world/routes.js`：连接村屋、码头和鸟居的村道；同材质路面合并绘制。
- `toon/materials.js`：保留 three.js 阴影管线的卡通材质，以及连续的几何描边。
- `world/boats.js`：四艘渔船、一艘小帆船和一艘小渡轮；船体、舷窗与驾驶舱已按审查意见修正。
- `world/harbor.js`：石岸、栈桥、防波堤与灯塔。
- `world/houses.js`：八座坡屋顶小屋、鱼市棚、鸟居。
- `world/props.js`：树木、木箱、晾鱼架、渔网架、吊杆、浮标和海鸥。
- `world/water.js`：海岸控制点、CPU/GPU 共用波形、卡通水面 shader。
- `world/constants.js`：统一水位、岛台半径、安全摆放半径与越界告警。
- `world/merge.js`：按材质合并静态几何体，降低 Draw Call。
- `审查修订报告.md`：P0～P2 共 23 条修订与实际验证结果。
- `world/puddles.js`：石岸水洼与天空色倒映、雨滴圆环。
- `weather/shared.js`：天气 shader 共用的时间、雨量、太阳与湿润参数。
- `weather/rain.js`：固定种子的 GPU 雨丝，按视角逆光增亮。
- `weather/splashes.js`：GPU 驱动的落点溅射。
- 相机 FOV 25°；太阳方向 `STATE.sunDir`；日照强度 3.0；阴影贴图 2048²；渲染像素比上限 2。
- 窄屏通过相机 `zoom` 自动缩小取景，使整个扩大后的岛台保持可见。
- 左上角显示实际 `renderer.info.render.calls`；本次浏览器检查观景模式为 141，步行模式为 86～104，控制台无报错。
